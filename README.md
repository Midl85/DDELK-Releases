# DDELK для Windows

Установщики и обновления каталога домов «Доступный дом СТ».

Скачайте DDELK-Setup.exe из последнего [релиза](https://github.com/Midl85/DDELK-Releases/releases/latest).
Для установки не нужен аккаунт GitHub. После установки новые версии проверяются автоматически.
Ручная проверка доступна через «О приложении» внизу окна.

Исходники хранятся отдельно в закрытом репозитории. macOS-сборки здесь не публикуются.
